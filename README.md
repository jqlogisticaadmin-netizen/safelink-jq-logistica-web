# SafeLink — documentação pública

Esta publicação do GitHub Pages é destinada somente à documentação técnica pública e a conteúdos estáticos compatíveis.

**Não é o aplicativo comercial e não oferece login.** O Script Mestre SafeLink v2.0 determina Cloudflare Pages para hospedar a aplicação comercial com autenticação. A URL de produção será divulgada somente depois de configurar e validar o ambiente.

O repositório oficial do código permanece privado: jqlogisticaadmin-netizen/safelink-jq-logistica. Não publicar credenciais, dados pessoais, dados operacionais ou chaves privilegiadas.
